# W31 — The owner's word keeps its authority; the rest of memory stays honest (v2)

Owner decisions, 2026-10-01:

- **Authority:** the owner's Telegram conversation is what carries authority. Every connector
  message is observation, including the owner's own lines in Kakao or Slack rooms.
- **Lessons stay:** a lesson the agent learns from observation is memory and stays ("그건 작업의
  교훈이라 중요한거지 그것도 기억이잖아?").
- **Scope:** only the owner conversation is told apart; the connectors are not labelled one by one.

Evidence:

- The Agent Memory Atlas review of `6738c694` (2026-09-28), with each point checked against
  `7dd858144`.
- Live counts. The 28 active rules: 14 were written in owner Telegram turns, 12 lessons in
  source-change turns, and 2 by hand on the owner's instruction. On 09-30 the daemon took 167
  source-change inputs and 4 owner messages.

## Out of scope

- An approval queue before memory lands (Atlas "human review"). The agent judges and the owner
  corrects in words.
- Deleting memory. Records and links are appended, never removed.
- Scope enforcement on the development memory surface. That matters once members share a database.
