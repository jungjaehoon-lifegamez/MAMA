# ChatGPT "Computer History" (2026-08-13/14 출시) — 어필 포인트와 MAMA 함의

> 오너 지시 리서치. 렌즈는 유저 어필(기술 스택 아님) + MAMA 함의. 같은 주에 Grok Bot(8/11)과
> 함께 — 양대 메이저가 "상시·능동·기억 기반 어시스턴트"로 수렴하는 주간.

## 무엇인가

ChatGPT Mac 데스크탑의 옵트인 기능. macOS 접근성 이벤트(클릭·타이핑·단축키·앱 전환)를
기록해 대화 컨텍스트로 쓴다. 스크린샷 기반 Chronicle 프리뷰를 대체("rebuilt, not renamed").
Pro/Business/Enterprise, 기본 꺼짐, EEA/UK/스위스 제외 시작.

## 유저 어필 포인트 (그들의 언어)

1. **"쉬고 와서 '나 뭐 하고 있었지?'라고 물어본다"** — 자기 작업의 연속성. 컨텍스트를
   설명해줄 필요가 없는 어시스턴트.
2. **"하던 일을 마저 끝내준다"** — finish tasks you're in the middle of.
3. **"하루 요약을 만들어준다"** — 우리의 "도착하는 메시지"와 같은 어필, 기질만 다름(그들=내
   컴퓨터 활동, 우리=채널).
4. **반복 패턴 → 스킬/자동화 승격 제안** — 시스템이 관찰로 자동화를 *제안*한다.
5. **프라이버시가 곧 기능** — 스크린샷·녹음·마이크 없음(반-Recall 프레임 명시), 로컬 저장,
   **Finder에서 메모리 파일 직접 열람**, 앱별 포함 제어, 10분 전~전체 소급 삭제.
   기본 꺼짐+옵트인 자체를 신뢰 자산으로 마케팅.

## 구조적 독해 — MAMA와의 관계

- **기질이 다르다(경쟁 아님, 인접)**: Computer History는 **내가 내 컴퓨터에서 한 일**을
  기억한다. MAMA는 **채널에서 일어난 일(남들이 말한 것, 조직의 사건)**을 기억한다.
  전자는 개인 활동 로그, 후자는 출처 있는 조직 기록. 겹치지 않지만 같은 감정을 판다:
  "설명 안 해도 아는 어시스턴트".
- **수렴 신호(중요)**: 같은 주에 xAI는 상시 에이전트(Grok Bot), OpenAI는 앰비언트 컨텍스트
  +스킬 제안+예약 태스크. 양대 메이저가 MAMA의 카테고리(상시·능동·기억)를 양방향에서 검증 중.
  단 **조직의 뇌(채널·팀·증거) 축은 둘 다 비어 있다** — Grok은 단일유저 로스터, OpenAI는
  단일유저 단일머신.
- **정직한 주의**: "Finder에서 메모리 파일 열람+소급 삭제"는 Grok의 "감사 뷰 coming"과 달리
  **점검 가능성의 실물**이다. "Built to be checked"를 우리만의 것으로 말할 수 없게 됐다 —
  우리의 차별점은 이제 열람이 아니라 **인과(무엇이 왜 바뀌었는지, cause 96.9% 실측)**로
  좁혀서 말해야 정확하다.

## 흡수할 것

1. **"나 뭐 하고 있었지?" 질문의 마케팅** — MAMA는 채널 버전으로 이미 답한다(델타 연속성,
   "지난 리포트 이후 무엇이 변했나"). 이 질문 형태로 팔아본 적이 없다.
2. **패턴→자동화 '제안' 모드** — 우리 트리거 루프는 조용히 자가 저작한다. "이 반복을
   자동화할까요?"로 오너에게 제안하는 표면(P4 에스컬레이션 인접)이 더 관계적이고, 그들이
   방금 이 UX를 대중화했다.
3. **소급 삭제 UX** — "방금 10분 지워줘"는 기억 신뢰의 좋은 관용구. 우리 메모리에도 이식
   가능한 작은 표면.
4. **옵트인·기본꺼짐을 자산으로 서사화** — 우리는 이미 그렇게 동작하나(커넥터별 opt-in)
   그것을 신뢰 마케팅으로 쓴 적 없음.
