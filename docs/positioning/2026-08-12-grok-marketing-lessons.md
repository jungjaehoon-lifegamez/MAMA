# Grok Bot 마케팅에서 배운 것 — MAMA 포지셔닝 노트

> 경쟁·비교우위 문서가 아니다. Grok Bot(xAI, 2026-08-11 출시)의 마케팅이 **무엇을 잘했는지**만 뽑아 MAMA에 흡수한다. Grok이 잘한 것은 하나다: **기술을 감정으로 번역했다.** 우리는 기술은 있는데 그 번역이 약하다.

## 5교훈과 MAMA 적용

### ① 기능을 관계로 번역한다
- **Grok**: "메모리·persistence·orchestration"을 안 판다. "동료에게 일을 넘긴다(hand work to a teammate)"를 판다.
- **근거**: AI 위임은 대인 비용(체면·관계)이 없어 사람이 더 기꺼이 맡긴다. MIT/BCG 2025 — 임원 76%가 에이전틱 AI를 "도구가 아닌 동료"로 인식.
- **MAMA 적용**: "MCP 메모리 서버 + 오퍼레이터 런타임"으로 설명하는 순간 도구가 된다. "당신 대신 지켜보고 정리하는 존재"로 설명해야 관계가 된다.
- **실측 갭**: README 태그라인("you read every channel yourself → MAMA reads them instead")은 이미 관계다. 그러나 바로 다음 문단 "always-on agent server, like Home Assistant or Plex"가 도구 프레임으로 되돌린다. 관계를 한 박자 더 유지할 것.

### ② 구매자가 자기 사례를 발견하게 한다 (폭으로 설득)
- **Grok**: sales·finance·eng·ops를 나열 — "buyers see their own use case reflected."
- **MAMA 적용**: 지금 "decision evolution"은 추상적이다. 우리 실제 라이브 장면이 훨씬 강하다:
  - "카카오방에서 3일 전 요청받은 건이 아직 아무 데도 없습니다."
  - "트렐로 카드가 3주간 조용히 어긋나 있었습니다 — 지금 갱신했습니다."
  - "이 마감이 임박했는데 담당자 확인이 비어 있습니다."
- 이 장면들은 실제 운영 로그에 있다. 마케팅 자산인데 안 쓰고 있다.

### ③ 통증을 언어화한다
- **Grok**: "노트를 복사할 필요 없이" — 통증을 명시.
- **MAMA 적용**: MAMA가 없애는 통증 문구:
  - "왜 그렇게 결정했는지 다시 설명하지 않아도 된다."
  - "물어본 게 조용히 사라지지 않는다."
  - "무엇이 바뀌었는지, 왜 바뀌었는지 매번 캐지 않아도 된다."

### ④ 감정 훅에 영수증을 붙인다 (여기가 우리 자산)
- **Grok**: "24/7·자율·팀원" — 근거 없는 감정. 리서치 만장일치 약점: "독립 검증 0", "2~3배 생산성에 벤치마크 없음."
- **MAMA 적용**: 같은 감정 훅("항상 지켜본다")을 쓰되 **증명을 붙인다**:
  - "항상 지켜본다" → 침묵하면 알린다(독립 워치독)
  - "당신 대신 판단한다" → 모든 변경이 원인을 댄다(cause_kind, changes_read)
  - "믿고 맡겨라" → 믿을 근거를 준다(증거 원장). 신뢰를 **요구**하지 않고 **증명**한다.
- README "Every claim links to its source" 태그라인이 이미 이 방식이다. 이 원칙을 전면에.

### ⑤ 정직한 베타도 마케팅이다
- **Grok**: "explicitly a beta, prices high, economics incomplete"를 인정받는다.
- **MAMA 적용**: README "Our numbers, including the bad ones"(84% no-op, 캐시 15.9x, cause 귀속 저조)가 이미 이 정직함 자산이다. Grok은 숨기고 우리는 공개 — 이것 자체가 신뢰 마케팅. 유지·강화.

## 한 줄 요약
Grok은 신뢰를 **유도**하고 근거를 안 준다. MAMA는 같은 감정 훅에 **영수증**을 붙인다. Gartner 2026("85%가 외부 통신에 사람 감독 요구")이 우리 승인-게이트 설계를 시장 흐름의 선두로 만든다.

## 주의
이건 Grok의 검증 안 된 주장(2~3배 등)을 흉내내자는 게 아니다. 정반대로, 우리 차별점은 **검증 가능성 그 자체**다. 감정을 파는 법은 배우되, 근거 없는 감정은 팔지 않는다.
