# Grok Bot (2026-08-11 출시) 실사용 사례와 MAMA의 구조적 차이

> 2026-08-13 리서치. 8/12의 마케팅 학습(같은 폴더)에 이은 사용사례·아키텍처 대조.
> 결론 먼저: xAI가 우리와 같은 베팅("노트북을 덮어도 일이 계속되는 상시 에이전트")에
> 진입했고, 이는 시장 검증이다. 차이는 신뢰 모델에 있다 — 그들은 "당신인 척 행동"을
> 팔고 감사(audit)는 "coming"이며, 우리는 증거·경계·승인을 먼저 지었다.

## Grok Bot이 무엇인가 (8/11 베타)

- 유저당 영속 클라우드 VM 1대 위에 **이름 붙은 에이전트 로스터**("동료처럼 메시지하라").
  각 에이전트가 브라우저·파일시스템·터미널·MCP 커넥터·computer-use를 갖고 상시 가동.
- 워크플로를 **화면 녹화 한 번으로 학습**(API 불요), 스케줄 루틴, 에이전트 간 자율 메시징.
- 인증은 handoff 패턴: 비밀번호·2FA·결제는 봇이 화면을 넘기고 사람이 입력.
- 가격: SuperGrok Heavy $300/월(또는 Cursor 번들), 무료 티어 없음.
- 동시에 companions(Ani 등)는 7/24 은퇴 — 파라소셜 실험을 접고 업무 에이전트에 집중.

## 실사용 사례 (문서화된 것)

벤더 가격 협상(유저 목소리로), 스토어 고객지원 운영, CRM 상시 최신화(Salesforce를
브라우저로 사람처럼 탐색), Gmail 보이스로 아웃바운드 작성·발송, 뉴스레터 통계 추출
(화면 녹화 1회 학습), X 계정 30분 주기 모니터링, 이벤트 지원자 ICP 스크리닝,
커뮤니티 운영(주 20시간+ 절감 주장), 90~120분 세일즈 플레이 95% 자동화.

## 구조적 차이 (그들 문서·리뷰가 인정하는 것 기준)

| 축 | Grok Bot | MAMA |
|---|---|---|
| 실행 위치 | xAI 클라우드 VM(폐쇄) | 로컬 데몬, 데이터 주권(~/.mama) |
| 에이전트 신원 | 로스터가 **유저로서** 바깥에 행동(유저 보이스로 발송·협상) | 오퍼레이터는 오너와 구별되는 정체성, 바깥 발화는 승인 우선(반사 응답만 기본) |
| 보안 경계 | **봇들이 한 컴퓨터 공유 — 봇은 보안 경계가 아님**(공식 문서), 파일·세션·자격증명이 로스터 전체에 노출 | 엔벨로프 집행·스코프 바인딩·채널 grant·레인별 툴 허용목록이 아키텍처 자체 |
| 검증/감사 | 감사 뷰 "coming", 승인해도 이미 실행된 작업 비가역, 테스트 런이 실제 작업 수행 | 증거 원장 라이브 실측(cause 귀속 96.9%), 툴 트레이스, 레인 검증, changes_read/provenance |
| 메모리 | 에이전트별 작업 상태·파일·세션 | 결정 진화 그래프 + 스코프 격리 + truth projection — 조직 지식 |
| 팀/조직 | 단일 유저 제품(로스터=한 사람의 부하들) | v1.0 = 오너가 멤버 인증·레벨 부여하는 조직의 뇌(로드맵) |
| 가격/개방 | $300/월, 폐쇄 | OSS, 로컬 |

리뷰들이 이미 지적하는 그들의 약점 = 우리의 기존 원칙: "베타에 고객 데이터·결제·프로덕션을
맡기지 말라", 공유 VM 위험, 비가역 실행. 우리는 반대로 관측-우선·비가역만 차단·증거 필수를
먼저 지었고 실측치가 있다.

## 흡수할 것 (경쟁이 아니라 학습)

1. **"동료처럼 메시지하라" 온보딩** — 설정 마법사 대신 자연어 위임이 진입 장벽 제로.
   우리 브리프 시스템(brief-*.md)은 이미 유사 구조 — 표면화가 부족할 뿐.
2. **이름 붙은 에이전트 로스터의 가시성** — 우리 워크오더 kind(board/wiki/temporal/memory)는
   내부 개념. "누가 무슨 일을 하는 동료인가"로 보여주면 같은 자산이 제품이 된다.
3. **화면 녹화 학습** — 무겁지만 방향 주목: 시연-기반 워크플로 티칭. 장기 후보.
4. **handoff 인증 패턴** — 자격증명을 모델에 안 주고 사람이 화면에서 입력. 우리 커넥터
   인증 플로우와 HITL 승인 계층에 그대로 부합하는 패턴.
5. **포지셔닝 문장**: "그들은 당신인 척 일하는 봇을 팔고 감사는 '곧'이라 한다. MAMA는
   무엇이 왜 바뀌었는지 증명하는 오퍼레이터다 — 그리고 곧 팀 전체의 뇌가 된다."
