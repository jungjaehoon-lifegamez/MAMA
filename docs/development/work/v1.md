## The 1.0 gate

1.0 ships when all four hold.

- **G1 Fresh install.** On a clean macOS user account, a clean Ubuntu 24.04 LTS host (proposed:
  the distribution CI runs on) and the Docker image, a person who has not used MAMA follows only the
  docs from nothing to: a DM reply, one connected source recorded as work, an evidence-backed answer
  to "who is working on what", and the next scheduled report. Each run records its steps, its time
  and every place the person had to leave the docs. The runs never touch this machine's live
  `~/.mama` or `~/.claude/mama-memory.db`. Linux and Docker work is tested on the owner's Steam
  Deck (SteamOS, x86-64; owner, 2026-10-15). SteamOS is not Ubuntu and keeps its system read-only,
  so L5 settles where the native Linux run happens: on SteamOS itself, which then becomes the
  reference distribution, or on a native Ubuntu host. A container does not count as the Linux run;
  it tests the Docker path.
- **G2 Upgrade.** An install of the release before 1.0, with records, sessions and settings in it,
  upgrades to 1.0 by the documented command and keeps them. Every 1.x release passes the same check.
- **G3 Owner flow.** C1–C5 ([plan](../plan.md#owner-checks)) are accepted by the owner on live data,
  and the daily self-check (#502) holds for a stretch the owner accepts (proposed: seven days in a
  row with section 3 and 4 lines matching the turn's traces).
- **G4 Nothing unverified is offered.** Every messenger, source and feature that `mama init` or the
  docs offer has run live on a fresh install, or both label it experimental.

`~/.mama` stays a disposable testbed on the development machine (AGENTS.md). A 1.0 user's data is
not disposable: from 1.0 an upgrade keeps it (G2, R4, R5).

## Not in 1.0

- Windows (owner, 2026-10-15). The Docker image may run under Docker Desktop on Windows; that is
  untested and not claimed.
- API keys and local models: MAMA signs in through the Claude and Codex CLIs.
- A browser admin panel: administration stays an interactive owner request in chat (AGENTS.md).
- A translated viewer, mobile and desktop apps, a skills marketplace, importers from other agents.
