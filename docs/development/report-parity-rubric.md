# Report Parity Rubric (6항목)

S1 스펙 done-수단: "the 07-30 six-item comparison, re-run against a
**checked-in** rubric, scores parity." 이 문서가 그 체크인이다.
(v1, 2026-07-31 — 07-30 비교의 원문 항목이 세션 컴팩션으로 유실되어 스펙의
패리티 의도로 재구성함. 이후 개정은 이 파일이 유일한 권위.)

**용법:** 구 리포트 레그(트리거 루프 full report)와 컨덕터 레그의 산출을
같은 날 같은 창으로 비교한다. 각 항목 pass/fail. **패리티 = 6/6이 3일 연속**
— 통과 시 컨덕터 레그로 권위 전환(구 레그는 그때까지 권위 유지).

| #   | 항목        | 판정 기준 (라이브 대조)                                                                                        |
| --- | ----------- | -------------------------------------------------------------------------------------------------------------- |
| 1   | 보드 정확도 | 리포트의 open/review 카운트·항목이 `task_list` 라이브 결과와 일치 (로그 프로젝션 금지)                         |
| 2   | 델타 우선   | 지난 성공 리포트 이후 **변한 것**을 이름으로 서술 — 보드 전체 재진술이 아님 (`changes_read` since=anchor 대조) |
| 3   | 원인 인용   | 서술된 각 변경이 effects 원장의 cause(kind/event ids)와 연결되고, unattributed는 unattributed로 표기           |
| 4   | 일정 교차   | 임박 마감이 `schedule_upcoming` 결과와 교차 검증되어 표기                                                      |
| 5   | 전달 온전성 | 오너 채널 도착 + 청크 유실 없음 (전달 원장 확인)                                                               |
| 6   | 정직성      | 읽지 않은 것을 주장하지 않음 — 페이지 한계(`returned < total`), 커버리지 분모, 미검증 항목이 명시됨            |

**기록:** 비교 1회당 아래 표를 이 파일 하단에 append (날짜, 레그별 6항목,
판정자). 3연속 6/6 도달 시 전환 결정을 오너에게 상신.
